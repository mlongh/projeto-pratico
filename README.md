# Projeto Prático - To-Do List

## Funcionalidades

### Lista de Tarefas com Prioridade
Esta funcionalidade permitirá que o usuário cadastre tarefas e defina um nível 
de prioridade para cada uma (baixa, média ou alta). As tarefas serão exibidas 
em uma lista ordenada automaticamente pela prioridade, facilitando a 
organização do dia a dia. O usuário também poderá marcar tarefas como 
concluídas e filtrar a visualização por status (pendente ou concluída).

## Versionamento Semântico

### O que é Versionamento Semântico
Versionamento Semântico é um padrão amplamente utilizado para numerar 
versões de software de forma clara e previsível. Ele permite que desenvolvedores 
e usuários entendam, apenas olhando o número da versão, se uma atualização traz 
mudanças que quebram compatibilidade, novas funcionalidades ou apenas correções.

### O que significa MAJOR.MINOR.PATCH?
- MAJOR: Incrementado quando há alterações que quebram a compatibilidade com versões anteriores.
- MINOR: Incrementado quando há novas funcionalidades adicionadas, sem quebrar a compatibilidade.
- PATCH: Incrementado quando há correções de bugs ou pequenas alterações que não quebram a compatibilidade.

### Exemplo prático de Versionamento Semântico
- 1.0.0: Versão inicial.
- 1.1.0: Adição de nova funcionalidade.
- 1.1.1: Correção de bug.
- 2.0.0: Quebra de compatibilidade.

### Quando incrementar cada parte?
- MAJOR: Quando há alterações que quebram a compatibilidade com versões anteriores.
- MINOR: Quando há novas funcionalidades adicionadas, sem quebrar a compatibilidade.
- PATCH: Quando há correções de bugs ou pequenas alterações que não quebram a compatibilidade.
