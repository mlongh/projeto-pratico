# Projeto Pratico - To-Do List

## Funcionalidades

### Lista de Tarefas com Prioridade
Esta funcionalidade permitirá que o usuário cadastre tarefas e defina um nível 
de prioridade para cada uma (baixa, média ou alta). As tarefas serão exibidas 
em uma lista ordenada automaticamente pela prioridade, facilitando a 
organização do dia a dia. O usuário também poderá marcar tarefas como 
concluídas e filtrar a visualização por status (pendente ou concluída).
